# Debug build artifacts

This directory is reserved for the STM32CubeIDE Debug output for `timer_01_basic`.

The original local project contains generated `.elf`, `.o`, `.map`, `.list`, dependency and make files. The GitHub connector used for this upload can create UTF-8 text files, but cannot upload binary `.elf`/`.o` artifacts. Keep the local `Debug/` output for reproducible local builds; source and project configuration belong in Git.
